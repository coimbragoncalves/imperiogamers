## 🎨 Cores do Site

SE basea nas fotos que irei mandar



### Como Admin:

1. **Fazer Login:**
   - Clique em "Entrar" no topo da página
   - Use as credenciais de administrador

2. **Acessar Painel Admin:**
   - Após login, clique no botão "Admin" no topo

3. **Criar Conteúdo:**
   - No painel admin, clique em "Criar Artigo" ou "Criar Trailer"
   - Preencha título, descrição e escolha imagem de capa
   - Para artigos: escolha o tipo (Notícia/Review/Outro)
   - Para trailers: cole link do YouTube ou faça upload de vídeo
   - Upload de múltiplas imagens disponível

4. **Gerenciar Comentários:**
   - Aba "Comentários" no painel admin
   - Pode apagar ou ocultar comentários

5. **Configurar Anúncios:**
   - Aba "Anúncios" no painel admin
   - Cole scripts de anúncios
   - Cole conteúdo do arquivo sw.js
   - Escolha posições dos anúncios
   - Ligue/desligue anúncios com o switch

### Como Usuário:

1. **Criar Conta:**
   - Clique em "Entrar"
   - Escolha "Criar conta"
   - Digite email e senha
   - Escolha nome de usuário e foto (opcional)

2. **Comentar Sem Login:**
   - Vá até qualquer notícia/trailer
   - Digite seu nome de usuário temporário
   - Escreva o comentário e envie

3. **Reagir:**
   - Use os botões 👍 Gostei e 👎 Não Gostei em qualquer conteúdo
